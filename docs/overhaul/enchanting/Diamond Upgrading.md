[[Enchanting Overhaul]]

Apply a diamond to any equipment in a smithing table with a Basic Upgrade Template to increase its stats.

Each diamond is:
- Weapons: +damage, +50% durability
	- Damage added scales with attack speed. \[0-1) attack speed is +2 damage, \[1-2) attack speed is +1 damage, and >=2 attack speed is +0.5 damage.
- Tools: +50% durability, +1 mining speed
- Armor: +50% durability, +1 shield (see: [[Armor Overhaul]])

Once you have access to an [[Altar]], you can create **Black Diamonds** with four void gems, which can be further applied to give your items another three upgrades.
Void gems are found exclusively in loot tables in [[The Beyond]].
