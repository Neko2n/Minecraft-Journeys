[[Early Game]] [[Going Above]]

The mortar is used to grind up items. You click to manually process something.

All dyes are now made in the mortar.

The mortar has a 2x2 grid of slots and crafts shapeless recipes only.

The millstone is an automatic version of the mortar which can process items in bulk. It has the same 2x2 crafting UI as the mortar, but without the manual button or a pestle slot, and has gears + a stone icon that rotates when the millstone is powered.
