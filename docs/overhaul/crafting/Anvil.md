[[Early Game]]

Anvil is now used exclusively for repairing.

Put an item and its repair material in, and then play a little timing minigame to determine how much durability you get. The minigame gets more difficult the more times you've repaired an item.

Naming things is now an innate feature of the name tag. Click while holding out a name tag to give it a name. Craft a named name tag together with an item to apply the name to it.
