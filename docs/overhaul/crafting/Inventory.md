[[Early Game]]

The inventory is changed from a 2x2 crafting grid to an "A + B = C" crafting system.

Here's some examples of early-game recipes:
- Twig + flint = crude knife
- Twig + pebbles = crude axe
- Twig + bone = crude pick
- Bone + bone = pike
- Flint + flint = firestarter
- Log + log = kindling
	- New building block, campfire without the ashes
	- Lighting it creates a normal campfire
- Kindling + \<fuel\> = campfire
	- Campfire + bone ash = soul campfire
	- Campfire + patina = cupric campfire
	- Clicking a campfire in the world with these items also converts it
- Twig + \<fuel\> = torch
	- Torch + bone ash = soul torch
	- You get the gist
- Log + \<knife\> = stripped log
	- Clicking logs in the world with a knife also strips them
	- Takes 1 durability from the knife
- Log + \<axe\> = 4 planks
	- Takes 1 durability from the axe
- Planks + planks = workbench
- \<foliage\> + \<knife\> = fiber
	- Takes 1 durability from the knife
- Fiber + fiber = rope
- Twig + leather = handle
- Handle + hardstone = hammer
- Planks + wax = treated planks
- Rawhide + wax = leather
- String + wax = candle
- 1 \[handle, twig\] + 1 treated planks = spoon
