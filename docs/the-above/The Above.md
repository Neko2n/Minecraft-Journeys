The Above is a new dimension that canonically exists above the overworld.

Most of the stone in this dimension is replaced with floatstone, a white stone which falls upward if exposed to air. Naturally generated floatstone won't float upward, and will instead give off particles to show that it's unstable, much like sand/gravel.

All dirt in this dimension's biomes is replaced with sunsilt. It's more reddish in color and has a softer, chunkier texture.

The Paradise Lost mod is a good reference for the color palette I'm going for.
