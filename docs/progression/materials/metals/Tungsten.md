[[Going Below]]

Tungsten is a rare tier-3 metal which generates exclusively in the lower caverns of [[The Below]] in unique boulder structures, around lava layer (y60).

The boulders it generates in are made of tremolite, a new purple-ish stone faintly resembling bedrock.

Tremolite and tungsten ore require a tier-3 tool to mine, but most tier-3 tools can only be obtained once you've gotten tungsten.
The exception to this is mechanical drills. This needs to be obvious so players aren't stuck thinking they need to wait to get a better pickaxe they'll never be able to obtain.
Maybe have abandoned mine structures with bits of tremolite and tungsten sitting next to broken mechanical drill setups and a blast furnace?

Tungsten's primary use is making the [[Crucible]], but it's also used in the creation of many Create items in place of the now-removed sturdy sheets.

Tungsten requires **blazing heat** to smelt. See: [[Smelting]]

The raw tungsten sprite is very cubic with chunks of tremolite still attached.
The tungsten ingot sprite is a perfect cube.

Tungsten's primary color palette is purple.

### Master Smithing Template

You can obtain a new smithing template from the [[Suspicious Trader]] once you've gotten to the below for the first time.

This template allows you to use one tungsten ingot to make a piece of gear completely unbreakable.

The trade for the template costs a resource (TBD) found only in [[The Between]], so it can only be obtained after beating the game.
