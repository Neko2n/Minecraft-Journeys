
The hammer and wrench are tools made with [[Copper]] used in the [[Assembly Table]] and to more easily modify building blocks.

The hammer can be used to quickly change blocks to different variants. The variants cycle from block -> stair -> slab -> corner -> block.
The hammer is also used to change furniture variants.

The wrench is used to rotate blocks in place. The wrench is also used to interact with kinetic contraptions from Create.
